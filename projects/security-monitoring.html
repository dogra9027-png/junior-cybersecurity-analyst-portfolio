Project 01 · Security Operations

Security Monitoring and Triage

A Python-based security monitoring project focused on analysing simulated security alerts, identifying suspicious activity, and documenting investigation findings.

Project type: Hands-on cybersecurity lab

Tools: Python, CSV, MITRE ATT&CK

Dataset: 7 simulated security alerts

Focus: Alert analysis, detection logic, triage and investigation

Project Objectives

  • Analyse security alerts using Python.
  • Identify suspicious IP addresses and activity patterns.
  • Detect brute-force attempts and port scanning activity.
  • Identify successful logins following suspicious activity.
  • Document findings and map relevant techniques to MITRE ATT&CK.

Detection Scenarios

  • Brute-force login attempts.
  • Potential port scanning activity.
  • High-severity security alerts.
  • Successful login following repeated failed attempts.

Key Results

  • Analysed 7 unique simulated security alerts.
  • Identified 8 detection rule matches.
  • Flagged 5 alerts for further investigation.
  • Created automated detection reports and unit tests.

Technical Implementation

Python scripts process the alert dataset and apply detection rules to identify suspicious behaviour. Unit tests help verify detection logic, including normal successful logins that should not trigger suspicious-activity alerts.

Documentation and Evidence

The project includes investigation reports, detection findings, alert analysis, and MITRE ATT&CK mapping.

Project Scope

This is a learning and portfolio project using simulated data. Findings demonstrate detection and investigation techniques; they do not represent monitoring of a live production environment.
