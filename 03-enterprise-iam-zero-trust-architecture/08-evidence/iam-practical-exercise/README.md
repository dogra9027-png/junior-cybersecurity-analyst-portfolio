# Practical IAM Access Review Exercise

## Overview

This exercise demonstrates a Python-based Identity and Access Management (IAM) access review workflow for a fictional organization.

The tool compares employee permissions against stated job requirements, identifies potentially excessive access, flags privileged permissions, and combines analyst decisions into a consolidated audit report.

The exercise uses simulated employee records and does not connect to live cloud environments.

## Objectives

- Analyse employee access assignments.
- Identify permissions that do not match stated job requirements.
- Flag privileged permissions for additional review.
- Apply least-privilege and RBAC principles.
- Document analyst decisions and recommended actions.
- Generate CSV-based access review and audit reports.

## Dataset

The simulated dataset contains:

- 5 fictional employees
- 10 permission assignments
- Multiple job roles
- Application, workspace, subscription, and account-level access
- Standard and privileged permissions

## How It Works

### 1. Access Analysis

The Python script compares each assigned permission against the stated business requirement.

It classifies records into:

- `MATCH`
- `REVIEW_REQUIRED`
- `PRIVILEGED_ACCESS_REVIEW`

### 2. Analyst Decision Tracking

A separate CSV file documents analyst decisions, justifications, and recommended next actions.

Decisions include:

- `REVOKE_PENDING_APPROVAL`
- `RETAIN_PENDING_VALIDATION`

Records without documented decisions remain `PENDING_REVIEW`.

### 3. Consolidated Reporting

The script combines access findings and analyst decisions into a consolidated CSV audit report.

## Execution

Run the following command from the project root:

```powershell
py "08-evidence\iam-practical-exercise\src\analyze_access.py"
```

The script reads both input CSV files and generates:

- `reports/access_review_report.csv` — initial access analysis, generated by the initial version of the script.
- `reports/consolidated_iam_audit_report.csv` — combined access findings and analyst decisions, generated by the current script.

## Limitations

This is a simulated practical exercise using fictional data.

No live Microsoft Entra ID, Azure, or AWS environment was connected. No production access permissions were retrieved, modified, or revoked.

The findings and analyst decisions are illustrative. Real access changes require validation and authorization from the appropriate managers and resource owners.
