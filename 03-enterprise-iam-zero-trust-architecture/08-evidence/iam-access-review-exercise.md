# Practical IAM Access Review Exercise

## 1. Exercise Overview

**Scenario:** You are an IAM analyst at NorthStar Technologies.

The IT department has provided an access report for five employees. Your responsibility is to identify excessive permissions, investigate access that does not match job responsibilities, and recommend corrective actions.

This is a simulated exercise using fictional users and access assignments.

## 2. Access Review Dataset

| User | Job Role | Assigned Access | Business Requirement |
|---|---|---|---|
| U001 – Sarah | HR Specialist | HR Application, Azure Contributor | HR Application |
| U002 – James | SOC Analyst | SIEM Read Access, Security Logs | SIEM and Security Logs |
| U003 – Maria | Finance Analyst | Finance Application, AWS Administrator | Finance Application |
| U004 – David | IT Support | User Support, Password Reset | User Support and Password Reset |
| U005 – Alex | Cloud Administrator | AWS Administrator, Azure Contributor | Cloud Administration |

## 3. Review Criteria

Evaluate each user's assigned permissions against their business responsibilities.

Consider:

- Does the access support the employee's job?
- Is the permission broader than necessary?
- Does the employee have administrative access without a clear business requirement?
- Should access be retained, reduced, or revoked?
- Does the access require additional approval?

## 5. Access Review Decisions

Use these decision categories:

- **Retain:** Access is appropriate for the job.
- **Reduce:** Access is broader than necessary.
- **Revoke:** Access is not justified by the business requirement.
- **Investigate:** More information or approval is required.

## 6. Security Recommendations

Based on the review, recommend improvements to:

- Role-based access control.
- Least-privilege permissions.
- Administrative account separation.
- Access approval procedures.
- Periodic access reviews.

## 7. Exercise Limitations

All users, roles, permissions, and business requirements in this exercise are fictional. No actual employee accounts or cloud permissions were accessed or modified.
